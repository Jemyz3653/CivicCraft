# CivicCraft 1.0.0

Initial release with 342 furniture variants, including 26 designs in every one of Minecraft 26.3's 13 woods and four museum stanchion colors.

- Sit on chairs, armchairs, stools, benches, sofas and waiting room seats.
- Build with dining tables, coffee tables, side tables and café tables.
- Open storage in cabinets, desks, shop counters, dressers, kitchen units, filing cabinets and crates.
- Display items on shelves, market stands, racks, pedestals, book stands and in glass cases.
- Place matching museum stanchions beside each other to connect them with ropes.

Wall shelves and market stands display the first three inventory slots. Glass cases, pedestals and book stands display the first slot. Bookcases, shop shelves and display racks show six. All 342 variants have Survival recipes and English and Russian names.

Requires Minecraft Java 26.3, Java 25, Fabric Loader 0.19.5+, and Fabric API 0.163.0+ for Minecraft 26.3. Install on both the server and its players' clients for multiplayer.
